# 工具参考

八个创作工具的参数、十五份工艺参考、分镜与区块校验、交付契约校验。

> 返回 [README](../README.md)

---

| 工具 | 阶段 | 作用 |
|---|---|---|
| `list_styles` | 2 | 检索已上架风格（当前 333 条），返回编号、名称、系列、适用题材、有无静帧、完整提示词 |
| `show_stills` | 2 | 将参考静帧作为图片写入对话，供风格判断 |
| `get_style` | 3 之后 | 读取单条风格的完整视觉规范 |
| `save_storyboard` | 4 | 提交分镜草稿并校验结构，渲染为时间轴与逐场清单 |
| `get_reference` | 6 | 按需取工艺参考：编排、运动、转场、排版、文字、调色、特效、粒子、镜头、图表、音画、音色、文案、版式、动效词表 |
| `save_outline` | 4（页面） | 提交页面区块清单并校验结构，渲染为可逐块审阅的结构表 |
| `save_animation` | 6（视频） | 校验 HTML 交付契约，落盘并挂载预览卡片 |
| `save_page` | 6（页面） | 校验单文件页面（外链与 file:// 不兼容写法），落盘并挂载页面卡片 |

## 参数

**`list_styles`**

| 参数 | 类型 | 说明 |
|---|---|---|
| `query` | string | 关键词、风格名或编号，如 `水墨` / `B3` |
| `series` | string | 限定系列：`AG` `M` `K` `Z` `H` `L` `V` `X` `R` `O` |
| `limit` | integer | 返回条数，默认 12，上限 50 |

**`show_stills`**

| 参数 | 类型 | 说明 |
|---|---|---|
| `ids` | string[] | 风格编号，单次上限 4 条 |
| `note` | string | 推荐理由，显示在图片上方 |

**`save_storyboard`**

| 参数 | 类型 | 说明 |
|---|---|---|
| `title` | string | 片名 |
| `style_id` | string | 已确认的风格编号 |
| `duration` | number | 总时长（秒） |
| `fps` | integer | 帧率，默认 30 |
| `aspect` | enum | `16:9` / `9:16` / `1:1` |
| `music` | enum | 配乐预设，留空按风格自动选择 |
| `shots[]` | object[] | 镜头列表，字段：`start` `end` `scene` `text` `camera` |

**`save_animation`**

| 参数 | 类型 | 说明 |
|---|---|---|
| `title` | string | 片名 |
| `html` | string | 完整的动画 HTML 正文，上限 2 MB；给了 `base_id` 时可省略 |
| `base_id` | string | 返工时填上一版的 id，继承未传的字段 |
| `style_id` | string | 采用的风格编号 |
| `storyboard_id` | string | 已确认的分镜 id |
| `duration` / `fps` | number | 覆盖分镜中的取值 |
| `music` | string | 覆盖分镜中的配乐 |
| `score_js` | string | 自写的配乐合成代码，**必填**；没有兜底引擎，不传就报错 |
| `beats` | object[] | 从动画代码导出的精确节奏点，卡点最可靠的来源 |
| `cues` | object[] | 镜头内部的重点时刻 |

### 返工

卡片只从 `save_animation` 的返回值里产生，所以**交付后改任何东西都要再调一次**。
只改一部分时传 `base_id`，系统读回上一版的正文与元数据，只覆盖这次传的字段：

| 想改什么 | 传什么 |
|---|---|
| 只换配乐 | `base_id` + `score_js` |
| 只改画面 | `base_id` + `html`（配乐自动沿用） |
| 改时长 | `base_id` + `duration`（切点重算） |

每次提交生成一张新卡片，但**工作区只留最新一版**：每次保存都会把上一版动画
（`<id>.html` + `<id>.score.js` + `<id>.json`）和上一版分镜一起删掉，中间稿不保留。
`base_id` 指向的那一版如果已被清理，会自动退到最近一版继续，所以返工不会中断。

导出同理：导出目录里上一次由本插件写出的成片会被删掉，只保留这一次的；用户自己
放在同一目录里的其他文件不会被碰。

**`save_outline`**（页面）

| 参数 | 类型 | 说明 |
|---|---|---|
| `title` | string | 页面名称，必填 |
| `style_id` | string | 已拍板的风格编号 |
| `aspect` | string | `16:9` / `9:16` / `1:1`，默认 `16:9` |
| `sections` | array | 区块列表，必填。每项含 `name`（必填）/ `purpose` / `content` / `layout` / `text` |

**`save_page`**（页面）

| 参数 | 类型 | 说明 |
|---|---|---|
| `title` | string | 页面名称，必填 |
| `style_id` | string | 已拍板的风格编号 |
| `outline_id` | string | 区块清单 id，用于比对块数 |
| `html` | string | 单文件页面正文，必填，上限 2 MB |

保存时校验：完整 HTML 文档、无外链资源、无 `fetch` / `XMLHttpRequest` / `type="module"`。
警告项：缺 viewport、没有 `<section>`、区块数与 `<section>` 数不一致、未关联区块清单。

## 分镜校验

`save_storyboard` 检查以下结构问题，结果附在草稿卡片上：

| 检查项 | 示例输出 |
|---|---|
| 时间空档 | 第 2 场与上一场之间有 3s 空档 |
| 时间重叠 | 第 3 场与上一场时间重叠 |
| 起止倒置 | 第 2 场的结束时间不大于开始时间 |
| 超出总时长 | 第 4 场超出总时长 8s |
| 缺画面描述 | 第 2 场没有写画面内容 |
| 字幕过长 | 第 1 场字幕 19 字，2s 的镜头最多约 11 字，删到只剩一件事 |
| 字幕有套话 | 第 1 场字幕有套话「赋能、让我们一起」，换成具体的东西 |
| 场次过少 | 只有 1 场：分镜至少拆成 3 场才有节奏 |
| 时长不齐 | 各场时长合计 6s，与总时长 8s 不一致 |

字幕按每秒 5.5 字估算阅读上限——一条字幕只有停留的那一两秒可读。套话表只报警告，
引用或刻意使用时由 Agent 自行判断。文案本身的写法见 `flow.js` 的「文案标准」小节。

## 交付契约校验

`save_animation` 校验 HTML 是否满足预览与导出所需的接口：

| 检查项 | 原因 |
|---|---|
| 存在 `window.renderAt(t)` | 导出逐帧驱动，`t` 为秒，同一 `t` 须渲染同一帧 |
| 存在 `<canvas>` | 录制基于 `canvas.captureStream()` |
| 无 `Math.random()` | 需固定种子以保证可复现 |
| 无 `requestAnimationFrame` 自播 | 自播会与导出器争夺时间轴 |
| 无外部脚本、图片、样式表 | 离线可复现，并规避供应链风险 |
| 关联了分镜 | 否则卡片标注「未经用户拍板」 |
