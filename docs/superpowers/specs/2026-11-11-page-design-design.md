# 创作模式：一个模式，两条流水线，由 Agent 判断

日期：2026-11-11（第三版，按用户要求改回单模式）
状态：待确认

## 一、要解决的问题

现在的创作模式只有一个产物：**视频**。六个工具从「分镜」一路服务到「导出 MP4」。

用户要的是：**同一个「创作模式」里，既能做视频，也能做 UI 页面设计**；到底做哪一种，
由 Agent 根据用户的话自己判断，不要分成两个模式让用户去选。

## 二、选定方案

**一个模式，一套工具，两条流水线。**

```
创作模式
├─ Agent 判断：做视频 还是 做页面
├─ 视频流水线：分镜 → 动画 → 卡片（预览 + 导出 MP4）
└─ 页面流水线：区块 → 页面 → 卡片（预览 + 下载 HTML）
```

工具放在一起，由 Agent 按判断结果选用：做视频时不碰 `save_page`，做页面时不碰
`save_storyboard`。这不是靠物理隔离，是靠流程约束（`flow.js` 里写明什么时候用哪个）。

### 考虑过但否掉的

| 方案 | 为什么否掉 |
|---|---|
| 两个独立模式，工具物理隔离 | 用户要在一个模式里完成，不想先去模式选择器挑 |
| 一个模式但工具按前缀分成两套（`video_*` / `page_*`） | 名字冗长，且判断责任本来就在 Agent，前缀不解决任何问题 |
| 页面单独一套风格库 | 333 条风格的配色/排版取向对页面成立，重做不划算 |

## 四、怎么判断做哪一种

放在第 1 步，用用户的原话判断，**不要问「你要做哪种」**——用户已经说了。

| 信号 | 判定 |
|---|---|
| 视频、短片、宣传片、动画、片子、预告、MV、导出 MP4 | 视频 |
| 页面、落地页、官网、主页、界面、UI、网页、设计稿、组件、按钮 | 页面 |
| 两者都没有（例如「帮我介绍下这个产品」） | 追问一句用途，再判断 |

判断结果要说出来，一句话即可：「这次做页面。」用户不同意会纠正。
判断一旦定下，整条会话只走那一条流水线，不要中途换。

## 五、两条流水线

### 视频（不变）

```
问需求 → 推荐风格 → 拍板风格 → 分镜 → 拍板分镜 → 动画 → 卡片（预览 + 导出 MP4）
```

### 页面（新增）

```
问需求 → 推荐风格 → 拍板风格 → 区块清单 → 拍板区块 → 页面 → 卡片（预览 + 下载 HTML）
```

区块清单对应分镜：每块写清「这一段说什么、放什么内容、用什么版式、文案是什么」。
页面没有时间轴，所以没有秒数。

## 六、页面产物

单文件 HTML，双击就能在浏览器打开、能点、能滚动，**不接真实业务**。

### 6.1 硬约束：`file://` 下必须可用

| 禁止 | 原因 |
|---|---|
| `fetch` / `XMLHttpRequest` | `file://` 跨域，必失败 |
| `<script type="module">` | 同上 |
| 外链字体、图片、CDN | 断网即垮 |

### 6.2 允许的交互

| 允许 | 例子 |
|---|---|
| CSS 交互 | hover、focus、`:checked` 驱动的展开 |
| 滚动动效 | IntersectionObserver 进场、视差、sticky |
| 原生 JS | tab、手风琴、模态、下拉、轮播、数字滚动 |
| 前端校验 | 必填提示，**只提示不提交** |
| 假数据 | 图表、列表用写死的示例 |

不允许：真实接口、登录、支付、提交表单。

## 七、页面卡片

```
┌──────────────────────────────────────────────┐
│ ● 落地页 · 暗色科技        [桌面][平板][手机]  │
│ ┌──────────────────────────────────────────┐ │
│ │  首屏标题                                │ │
│ │  ──────                                  │ │
│ │  [ 按钮 ]                                │ │
│ └──────────────────────────────────────────┘ │
│ 1440 × 900 · 4 个区块   [下载 HTML] [复制代码] │
└──────────────────────────────────────────────┘
```

宽度切换只改 iframe 宽度（1440 / 834 / 390），页面自己响应式。
下载走现有导出通道，文件名是 `.html`，不经过录制。

## 九、已定的判断

- 页面预览默认 1440，可切 834 / 390
- 区块清单带「文案」列
- 下载 HTML 不附带截图
- 风格库共用 333 条，页面只取配色/字体/质感
- `moves` 词表（120 条）已在上一轮完成，不在这次范围内
- 判断结果用一句话说出来，不弹选择框

## 十、成功的样子

用户说「给我做一个 SaaS 落地页，暗色科技风」：

1. Agent 说「这次做页面」，然后给 2–3 张风格参考图
2. 用户点选一张，Agent 给区块清单（首屏 / 特性 / 案例 / 价格 / 页脚），改两句，点确认
3. 拿到卡片，能切桌面/手机宽度预览，点「下载 HTML」得到双击就能打开的文件

用户说「给我做个 30 秒的宣传片」：走原来的六步，卡片能导出 MP4。
