# 版式与页面结构

页面和视频最大的差别：视频有终点，页面没有。用户会滚动、会点、会拿手机打开。

这一份讲：网格、间距、区块类型、断点、对比度、触控目标。

---

## 一、先定宽度和网格

页面默认按桌面设计，宽度基准 **1440**。

| 项 | 值 | 说明 |
|---|---|---|
| 内容最大宽度 | 1200px | 超过就不再加宽，两侧留白 |
| 栅格 | 12 栏 | 列间距 24px |
| 页面左右内边距 | 80px（≥1200 时）| 窄屏按断点递减 |
| 满宽区块 | 100vw | 背景可以满宽，内容仍受 1200 限制 |

```css
.wrap{max-width:1200px;margin:0 auto;padding:0 80px}
@media (max-width:1024px){.wrap{padding:0 48px}}
@media (max-width:640px){.wrap{padding:0 24px}}
```

12 栏的好处是任何常见切分都成立：2×6、3×4、4×3、6×2。不要用 5 栏或 7 栏。

---

## 二、间距阶梯

只用这七个数，不要随手写 13px、27px：

```
4 · 8 · 16 · 24 · 32 · 48 · 64 · 96
```

| 用途 | 值 |
|---|---|
| 行内元素之间 | 8 |
| 图标与文字 | 8 |
| 卡片内部 | 24 |
| 卡片之间 | 24–32 |
| 区块内部（标题到内容） | 32–48 |
| 区块之间（上下留白） | 96–120 |
| 首屏顶部 | 96–160 |

**区块之间的留白要明显大于区块内部**，否则整页看起来是散的。

---

## 三、区块类型

一个落地页通常 4–6 块。每块只承担一个任务。

### 首屏（Hero）

| 要素 | 说明 |
|---|---|
| 主标题 | 一句话说清是什么，≤ 12 字 |
| 副标题 | 补充谁用、解决什么，≤ 30 字 |
| 主按钮 | 一个就够，文案是动词（「开始做一条」） |
| 视觉 | 产品截图 / 抽象图形 / 演示动图，占右侧或下方 |

首屏必须回答「这是什么」和「我该做什么」。两个问题答不上来，后面做得再好也没用。

### 特性（Features）

3 或 4 个，每个一张卡：图标 + 标题（≤8 字）+ 一句说明（≤25 字）。
**不要超过 4 个**——超过读者只会记住第一个和最后一个。

### 案例 / 数据（Proof）

三选一：客户 logo 墙、三个数字、一段引述。
数字要有单位与对比（「3.2s → 0.8s」比「大幅提速」有力）。

### 价格（Pricing）

2–3 档，中间那档标「推荐」。每档列 4–6 条差异，不要列全量功能。

### 页脚（Footer）

品牌、两三组链接、版权。**不要放一堆没人点的链接**。

---

## 四、断点

只用三个断点，多一个都嫌多。

| 名称 | 宽度 | 行为 |
|---|---|---|
| 桌面 | ≥1025px | 12 栏，左右 80px 内边距 |
| 平板 | 641–1024px | 特性从 3 列变 2 列，内边距 48px |
| 手机 | ≤640px | 全部单列，内边距 24px，字号下调一档 |

```css
@media (max-width:1024px){ .features{grid-template-columns:repeat(2,1fr)} }
@media (max-width:640px){ .features{grid-template-columns:1fr} }
```

**手机断点下不要出现横向滚动。** 检查方法：把宽度设成 390，看 `document.documentElement.scrollWidth` 是否等于 `clientWidth`。

---

## 五、字号与行高

页面比视频的字多得多，层级要更清楚。

| 层级 | 桌面 | 手机 | 行高 |
|---|---|---|---|
| 主标题 | 56–64px | 34–38px | 1.1 |
| 区块标题 | 36–40px | 26–28px | 1.2 |
| 卡片标题 | 20–22px | 18px | 1.3 |
| 正文 | 16–18px | 15–16px | 1.6 |
| 辅助文字 | 13–14px | 12–13px | 1.5 |

正文行高 1.6 是页面的标准，不要用 1.2（那是标题的）。

---

## 六、对比度

| 内容 | 最低对比度 |
|---|---|
| 正文（< 18px） | 4.5:1 |
| 大字（≥ 18px 粗体 / ≥ 24px） | 3:1 |
| 按钮文字 | 4.5:1 |
| 装饰性图形 | 无要求 |

深色页面最常见的问题：`#8a8a8a` 的字放在 `#111` 上只有 4.0:1，不达标。把次要文字提到 `#a8a8a8` 以上。

---

## 七、触控目标

手机上任何可点的东西，**最小 44×44px**。

```css
.btn{min-height:44px;padding:0 20px;display:inline-flex;align-items:center}
```

文字链接也要给足够的行高和间距（上下各 8px 内边距），否则手指点不中。

---

## 八、动效

页面动效只做三件事：**引导视线、反馈操作、交代层级**。超过就是噪音。

| 场景 | 时长 | 曲线 |
|---|---|---|
| hover 反馈 | 120–160ms | ease-out |
| 元素进场 | 300–500ms | ease-out |
| 展开 / 收起 | 200–300ms | ease-in-out |
| 滚动进场 | 400ms，延迟 0–120ms 错开 | ease-out |

滚动进场用 `IntersectionObserver`，不要监听 `scroll` 事件算位置：

```js
const io = new IntersectionObserver((es) => {
  for (const e of es) if (e.isIntersecting) { e.target.classList.add('in'); io.unobserve(e.target); }
}, { threshold: 0.2 });
document.querySelectorAll('[data-in]').forEach((el) => io.observe(el));
```

具体招式（视差、磁吸按钮、堆叠卡片…）取 `get_reference("moves")`，里面 120 条都有时序参数。

## 九、常见错误

| 错误 | 后果 | 修正 |
|---|---|---|
| 区块之间没留白 | 整页糊成一团 | 区块上下 96px 起 |
| 特性 6 个以上 | 读者一个都记不住 | 砍到 3–4 个 |
| 首屏没有按钮 | 用户不知道下一步 | 一个主按钮 |
| 手机断点横向滚动 | 体验崩坏 | 检查 390 宽 |
| 正文 14px 以下 | 手机上读不动 | 15px 起 |
| 对比度不足 | 看不清 | 正文 4.5:1 |
| 按钮 32px 高 | 手指点不中 | 44px |
| 每个区块都做滚动动效 | 眼花 | 只给 2–3 处 |
